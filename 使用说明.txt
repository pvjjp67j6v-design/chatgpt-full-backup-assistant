ChatGPT 全量备份助手

双击同目录的「ChatGPT全量备份助手.exe」运行，无需安装 Python。
本机 Edge 的浏览器连接组件已安装。换电脑、换 Edge 配置或重新安装浏览器后，
请先点击首页「安装 / 更新浏览器连接组件」，在 Tampermonkey 页面点击安装。
需要保留 Tampermonkey，允许该组件在 chatgpt.com 运行，并登录需要备份的账号。
原有 ChatGPT Exporter 可以继续使用；助手的连接组件不会改动原有导出设置。

一、使用
1. 设置一个「备份根目录」。默认是本程序所在目录。
2. 设置重试间隔（秒）、重试次数。默认 60 秒、3 次。
   首次尝试不计入重试次数。任一项为 0 则关闭自动重试。
3. 点击「一键导出并备份」。Edge 会在新标签页打开 ChatGPT。
4. 保持 EXE 和任务标签页打开，直到首页显示成功或失败。
   不需要手动选择对话，不需要手动点击三次导出。
5. 点击「打开备份目录」可查看结果。

二、保存结构
根目录\2026-11-16\chatgpt-export-json\
根目录\2026-11-16\chatgpt-export-markdown图片单独打包\
根目录\2026-11-16\chatgpt-export-markdown图片嵌套进MD\
根目录\2026-11-16\backup.log

JSON 为普通 JSON 数组文件，不是 JSON ZIP。
两种 Markdown 批量结果均为 ZIP：
- 图片单独打包：ZIP 内有 .md 和 assets 图片文件，保持相对引用。
- 图片嵌套进 MD：ZIP 内的每个 .md 使用 base64 嵌入图片。
每 25 条会话为一批，以控制内存及上传大小，因此每类可能包含多个分卷。
每个 ZIP 另附 _backup-manifest.json，用于核对会话清单与图片模式。
文件名含任务时间和编号，同一天再次备份也不会覆盖之前的文件。
日期采用新加坡时间，跨午夜的重试仍保存在本次开始时建立的日期目录。

三、导出内容
默认读取当前登录账号 / 当前工作空间下能访问的全部对话，并合并项目对话、去重。
上限为 20000 条；超过上限、分页不完整或图片无法下载会报告失败。
临时聊天、已删除聊天以及账号无权读取的内容无法补回。
文件名模板为 ChatGPT-{title}。开启可导出的思考过程、来源、24 小时制时间戳。
Markdown 元数据包含 title、source、create_time、update_time。
助手复用 ChatGPT Exporter 的解析与 Markdown 渲染逻辑；仅能保存网页接口实际提供的内容。

四、自动重试
网络异常、HTTP 错误、限流 / 等待倒计时、文件保存或校验失败都视为本次尝试失败。
统一按首页的重试间隔等待，不采用页面自身倒计时。
等待结束后打开 Edge 新标签页，重新加载 ChatGPT，再继续本次备份。
本次已下载的对话和成功保存的分卷会复用，已完成内容不会反复计数。
旧标签页失去本次任务权限，可以关闭。
达到重试次数或关闭自动重试后，显示失败及实际保存数量。
「停止」会停止任务并使浏览器任务失效；关闭 EXE 后不会继续自动重试。
失败后部分文件可能已经成功保存，请以日志中各类别的实际会话数为准。

五、结果与日志
首页记住上次导入 / 备份的日期、成功 / 失败、三类会话数量。
开始后会先记录「进行中」；若意外断电 / 强制结束，不能视为成功。
当天目录内的 backup.log 追加记录任务、失败原因、重试、分卷保存及三类实际会话数。
仅当三类结果均保存成功，且每批会话 ID、文件数与清单一致时，才显示全部成功。
「.任务缓存」存放本次续传所需的临时原始对话和状态，不是第四种正式导出。
停止且不再需要排查后可手动删除该缓存；保留三个正式分类目录及日志即可。

六、随附文件
备份设置.json：保存目录、重试设置及上次结果。请与 EXE 一起放在有写入权限的目录。
程序源码：构建脚本、连接组件、测试和第三方许可证，供维护使用。
自检结果.txt：文件保存及计数校验测试结果。
